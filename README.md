# TurnoSalud

**Universidad de las Fuerzas Armadas ESPE**  
**36845 - Aseguramiento de la Calidad de Software**

Ejercicio académico de aplicación del Perfil Básico de ISO/IEC 29110 a una aplicación web de agendamiento médico. El caso contempla una VSE de seis personas, doce semanas y un presupuesto de USD 18.000.

## Avance disponible

[Avance 1 - Erick Obando: selección del perfil y roles](01_Erick_Obando/TURNOSALUD_TALLER%201%20-%20U2%20V.1.0.pdf).

Incluye justificación del Perfil Básico, relación entre Gestión de Proyectos e Implementación de Software, distribución de roles, glosario y referencias.
